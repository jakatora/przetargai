# runbooks/

Procedury operacyjne i awaryjne PrzetargAI.

- `api-keys.md` — jak krok po kroku zdobyć wszystkie klucze API i konta.
- `bzp-api.md` — weryfikacja i diagnostyka integracji z API BZP.
- `deploy.md` — wdrożenie produkcyjne (Railway, Vercel, Codemagic, Stripe).
- `wdrozenie-firebase.md` — migracja backendu na Cloud Functions + Firestore (D-024).
- `incident.md` — reakcja na awarie i przywracanie bazy z kopii zapasowej.
