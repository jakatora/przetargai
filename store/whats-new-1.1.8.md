# PrzetargAI — teksty wydania 1.1.8

Wersja: **1.1.8** · Android `versionCode 20` (poprzednio 1.1.7 / 19) · Data: 2026-10-25

Zasady jak w `whats-new-1.1.7.md`: bez emoji (bullet `•` dozwolony), opis = faktyczne działanie.
Przy wydaniu podbić: `mobile/app.json` (1.1.8 / versionCode 20), `android/app/build.gradle`, `desktop/package.json` ORAZ `landing/wersja.json` (test `landingStrona` tego pilnuje).

## What's New — PL

```
• Aplikacja sama mówi, że jest nowa wersja — na Windows i przy APK ze strony pokazuje pasek z linkiem do pobrania (można odłożyć).
• Ekran Konto oraz Radar SWZ, Odpowiedź na wezwanie i Dokumenty do oferty mają etykiety po angielsku (pisma pozostają po polsku).
• Nowe źródło ogłoszeń: platformazakupowa.pl — a przy takim ogłoszeniu jednym dotknięciem pobierzesz tryb postępowania i listę załączników (SWZ) z linkami. Załącznik SWZ otworzysz od razu w Radarze SWZ — pytania do specyfikacji bez ręcznego wgrywania pliku.
```

## What's New — EN

```
• The app tells you when a new version is out — on Windows and for the website APK it shows a bar with a download link (can be dismissed).
• The Account screen plus the tender-document radar, reply-to-request and bid-documents tools now have English labels (letters stay in Polish).
• New notice source: platformazakupowa.pl — for such notices one tap fetches the procedure mode and the list of attachments (tender documents) with links. A tender-document attachment opens straight in the document radar — questions on the specification without uploading the file yourself.
```
